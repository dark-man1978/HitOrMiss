# Authentic app screenshots

Before submitting to F-Droid, capture the running app on an Android device.
Include the difficulty-selection screen, a game screen and the results screen.
Use screenshots without notifications or personal account information.

Save PNG files under:

- `fastlane/metadata/android/de-DE/images/phoneScreenshots/1.png`
- `fastlane/metadata/android/de-DE/images/phoneScreenshots/2.png`
- `fastlane/metadata/android/de-DE/images/phoneScreenshots/3.png`

The same German-language screenshots may be used in the en-US listing,
which explicitly states that the interface is in German.

No fabricated screenshots or screenshots of an HTML imitation are included.
The artwork overview sheets are image catalogues, not app screenshots.
